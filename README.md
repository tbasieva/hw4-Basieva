# Письма Эрдмана и Степановой — датасет для анализа

Здесь лежит таблица с письмами Николая Эрдмана и Ангелины Степановой (1928–1935), собранная из текстового файла `erdman.txt`. Письма разобраны на отдельные записи, у каждой есть дата, автор, исходный текст, лемматизированный текст и число слов. По этому датасету уже можно считать частотность, строить таймлайны и сравнивать авторов между собой.

## Что в CSV

`erdman_stepanova_letters.csv` (кодировка UTF-8, чтобы нормально открывалось в Excel). Колонки такие:

- **date** — дата письма, формат `YYYY-MM-DD`. Если дату вытащить не получилось, стоит `None`.
- **author** — либо `Эрдман`, либо `Степанова`, других значений нет.
- **text** — тело письма после чистки: без сносок, без служебных строк шапки, переносы строк схлопнуты в пробелы.
- **lemmatized_text** — те же слова, но приведённые к начальной форме через `pymorphy3`. Только кириллица/латиница/цифры.
- **word_count** — сколько токенов получилось после лемматизации. Считается по тому же списку слов, что попал в `lemmatized_text`, так что эти две колонки согласованы.

Всего писем — **68**.

## Как устроен разбор

Исходный файл читается целиком, нормализуются переводы строк (`\r\n` и `\r` → `\n`), сразу вырезаются сноски вида `[23]`. Дальше текст режется регуляркой `(?:\*\s*){3,}` — то есть по трём и более звёздочкам подряд. Всё, что получилось между разделителями, — потенциальное письмо.

Блоки, которые начинаются с `[Воспоминания`, пропускаются: воспоминания Степановой в датасет не идут. Блоки, в которых `get_author` не смог определить автора, тоже отбрасываются.

Для каждого блока:

1. Первые 15 строк считаются шапкой — по ним ищется дата. Заодно запоминается год из найденной даты (`last_year`), чтобы потом подставлять его в письма без года.
2. `clean_block` проходит по строкам сверху вниз, пока не начнётся тело. Пропускает пустые строки, служебные пометки (Москва, Баку, Заказное, До востребования, ул., Эрдман и т.п. — они перечислены в `header_words`), а также строки, которые `parse_date` опознал как дату. Всё остальное — тело письма.
3. Тело ещё раз чистится от `[N]`, пробелы схлопываются.
4. `get_author` смотрит последние 500 символов блока: если там встречается `николай`, `коля` или `н.` — автор Эрдман; если `лина` или `ангелина` — Степанова. Иначе `None`, и блок выкидывается.
5. `lemmatize_text` режет текст, оставляет только токены из `[а-яёa-z0-9]+`, каждый прогоняет через `morph.parse(w)[0].normal_form`. Длина этого списка и есть `word_count`.

После сбора всех строк датафрейм сортируется по дате, `None` уезжают в конец, чтобы не мешать хронологии.

## Про даты

Формат в источнике разный, поэтому `parse_date` перебирает варианты по очереди и возвращает первое совпадение:

- `DD.MM.YYYY`, `DD/MM/YY`, `DD-MM-YYYY` — двухзначный год превращается в `19YY`.
- `DD.Рим.YY` — римские числа от `I` до `XII` через словарь `roman_months`.
- `DD месяц YYYY` — месяц берётся из словаря `months`, куда занесены и полные названия, и сокращения (`янв`, `фев`, `мар` и т.д.).
- `DD месяц` без года — подставляется `last_year` из предыдущего письма.
- `месяц YYYY` — день ставится `01`.
- `месяц` без года — `01` плюс `last_year`.
- просто `YYYY` — получается `YYYY-01-01`.

Всё, что не подошло ни под один шаблон, даёт `None`.

## Чего в датасете нет

- Воспоминаний Степановой — они вырезаются ещё на этапе разбиения.
- Служебных строк вроде адреса, штампа «Заказное», пометок «До востребования» — они отсеиваются в `clean_block`.
- Сносок `[N]` — удаляются дважды: до разбиения и внутри блока.

## Известные ограничения

- Когда `parse_date` не распознаёт строку с датой, `clean_block` её не вырезает — она остаётся в начале `text` и попадает в лемматизацию (отсюда, например, лемма `ноябнуть` из «нояб.»).
- Автор определяется по концу блока. Если подпись не попала в последние 500 символов или её нет, письмо будет отброшено.
- `last_year` — глобальная переменная на весь прогон: если в источнике год «прыгает» назад, подстановка может ошибиться.
